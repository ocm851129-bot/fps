# TRIAD · 3인 아레나 FPS

고영훈(돌격소총), 하헌민(기관단총), 오대영(지정사수소총) 중 한 명을 선택해 AI 두 명과 겨루는 브라우저 FPS입니다. 실시간 온라인 멀티플레이는 포함하지 않습니다.

## 실행 주소

- 게임: https://triad-arena-sable.vercel.app/
- 저장소: https://github.com/ocm851129-bot/fps
- Vercel 프로젝트: `triad-arena`, GitHub `main` 브랜치 연결.

## 플레이

- 5점 선승, 3분 제한. 동점은 데스가 적은 순서로 판정하며 데스까지 같으면 무승부입니다.
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 좌우 드래그 조준, 사격 버튼 길게 누르기. 사격 버튼 위에서도 좌우 드래그가 가능합니다. 재장전 버튼과 질주 버튼을 제공합니다.
- PC: WASD 이동, 마우스 또는 좌우 방향키 조준, 클릭/Space 사격, Shift 질주, R 재장전, Esc 일시정지.
- 탄창이 비면 자동 재장전합니다. 재투입 후 1.3초 보호가 적용되며 사격하면 보호가 끝납니다.
- 터치 조작은 터치 기기에서 기본 활성화되며 메뉴에서 수동 전환할 수 있습니다. 가로 화면을 권장하며 세로 화면도 지원합니다.
- 루키/스탠다드/베테랑 AI 난이도, 일시정지 화면의 조준 감도 설정을 제공합니다.
- HTTPS로 한 번 접속한 뒤 서비스 워커 설치가 완료되면 오프라인 플레이가 가능합니다. 브라우저의 홈 화면 추가 기능을 사용할 수 있습니다. 전체 화면 지원은 브라우저에 따라 다릅니다.

## 로컬 실행

Node.js 22 이상. 외부 패키지 설치가 필요 없습니다.

```sh
npm test
npm run build
npm start
```

`http://localhost:3001`에서 실행됩니다. 배포 결과에는 허용된 게임 정적 파일만 포함합니다.

## Git / Vercel

게임 디렉터리를 독립 저장소 루트로 사용합니다. `vercel.json`이 프레임워크 Other, 빌드 `npm run build`, 출력 `dist`를 지정합니다. Vercel에서 해당 GitHub 저장소를 가져오면 기본 브랜치의 push가 production 배포를 트리거합니다. GitHub Actions는 게임 로직·터치 입력 테스트와 빌드를 실행합니다.

별도 백엔드, 데이터베이스 또는 환경변수는 필요 없습니다. `.env`, `.vercel`, 로컬 산출물은 Git에서 제외합니다.

## 검증 범위

자동 테스트는 충돌, 사격/엄폐, 재장전, 부활, 승패, AI 경기 완료, 여러 손가락 입력과 취소를 다룹니다. 모바일 브라우저 뷰포트 확인은 실제 iOS/Android 기기에서의 성능과 멀티터치 검증을 대체하지 않습니다.
