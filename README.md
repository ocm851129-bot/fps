# TRIAD · Special Operations

고영훈(돌격소총), 하헌민(기관단총), 오대영(지정사수소총)으로 플레이하는 모바일·PC 브라우저 FPS. AI 연습과 Supabase Realtime 기반 2~3인 온라인 초대 대전을 제공합니다.

- 게임: https://triad-arena-sable.vercel.app/
- 저장소: https://github.com/ocm851129-bot/fps
- Vercel: triad-arena, GitHub main 자동 배포

## 온라인 대전

1. 요원과 맵을 선택하고 **온라인 초대 대전 → 새 방 만들기**를 누릅니다.
2. **초대 링크 복사**로 친구에게 링크를 공유합니다. 친구는 **초대 링크로 입장**을 누릅니다.
3. 2명 이상이면 방장이 시작할 수 있습니다. 최대 3명이며 중복 요원은 남은 요원으로 배정됩니다.
4. 전투 중에는 입장할 수 없습니다. 방장이 나가거나 연결이 끊기면 참가자도 대기실로 돌아갑니다. 재경기는 새 방에서 시작합니다.

서울 리전의 Supabase 무료 프로젝트 `triad-arena-online`을 사용합니다. 위치·사격 입력은 방장 브라우저가 판정하고 상태를 약 15Hz로 전송합니다. 참가자는 이동 예측·위치 보정을 적용합니다. 초대 링크는 방 접근 수단이며 신뢰할 수 있는 친구끼리 사용하는 프로토타입입니다. 전용 권위 서버, 계정 인증, 매치메이킹, 안티치트는 아직 없습니다. 방장 기기의 성능·네트워크·백그라운드 탭 제한에 영향을 받으므로 게임 탭을 유지하세요.

`online-config.js`에는 브라우저용 공개 anon 키만 있습니다. 서비스 역할 키나 DB 비밀번호를 추가하지 마세요. 데이터베이스 테이블에 읽기/쓰기하지 않고 Realtime Broadcast/Presence만 사용합니다. 무료 사용량 한도에 따른 서비스 제한이 있을 수 있습니다. 유료 플랜은 신청하지 않았습니다.

## 전술 FPS 기능

- 더스트라인 컨테이너 야드 / 블랙사이트 실내 창고 두 맵. 창고 출입구·엄폐물·지붕·조명·외곽 우회로.
- 위장복·헬멧·고글·조끼·무전기·역할별 장비. 넓은 화면에서 선택 요원 3D 미리보기.
- Three.js 광원, PC 그림자, 총기 모델, 이동 애니메이션과 보간.
- 정밀 조준, 수직 반동, 헤드샷 1.8배 피해, 처치 알림, 온라인 명중 표시.
- 5점 선승 / 3분 제한. 동점은 데스가 적은 순서, 데스까지 같으면 무승부.
- AI 연습: 루키·스탠다드·베테랑, 엄폐물 경로 탐색과 좌우 이동.
- 모바일 해상도 제한·그림자 비활성화. WebGL 미지원 기기는 호환 렌더러.
- 자체 제작 맵과 모델이며 상용 게임의 자산을 복제하지 않습니다.

## 조작

PC: WASD 이동, 마우스 조준, 클릭/Space 사격, 우클릭/Q 정밀 조준, Shift 질주, R 재장전, Esc 메뉴.
모바일: 왼쪽 조이스틱 이동, 오른쪽 드래그 조준, 사격 버튼 길게 누르기, 조준·재장전·질주 버튼. 가로 화면 권장.
온라인에서는 메뉴를 열어도 전투가 계속됩니다. 탄창이 비면 자동 재장전하고 재투입 후 1.3초 보호(사격 시 해제)가 적용됩니다.
HTTPS 서비스 워커 설치 이후 AI 연습은 오프라인 사용 가능합니다. 온라인 대전에는 인터넷 연결이 필요합니다.

## 개발·배포

Node.js 22 이상:

```sh
npm ci
npm test
npm run build
npm start
```

로컬 주소는 http://localhost:3001 입니다. `dist`에는 허용한 게임 파일만 출력합니다. Supabase 클라이언트는 esbuild로 번들하며 CDN 실행 의존성이 없습니다. GitHub Actions는 테스트와 빌드를 실행하고 Vercel은 main 변경을 배포합니다.

검증: 게임 로직·터치·양쪽 맵·원격 입력 판정·온라인 일시정지·스냅샷 검증 자동 테스트. 실제 Supabase에서 3개 브라우저 클라이언트의 입장·요원 배정·시작을 확인했고, 창고 맵에서 원격 사격과 방장 종료 전파를 확인했습니다. 실제 휴대폰 성능 및 여러 인터넷 회선의 지연은 별도 실기 검증이 필요합니다.
